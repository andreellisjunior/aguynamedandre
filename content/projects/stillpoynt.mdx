## Overview

StillPoynt is a mindful productivity and spiritual wellness app built around a simple idea: do less, mean more. It helps users capture commitments, clarify what matters, focus deeply, and return to scripture — all within a calm, distraction-free interface that works across devices and offline.

## Key Features

### Commitments, not chores

- Capture commitments quickly from anywhere with a floating quick-add button and keyboard shortcuts
- Clarify tasks by timeframe, effort level, and category
- Use the Decide workflow to prioritize deep work using impact, confidence, and time estimates
- Focus on up to three daily priorities with the Top 3 selector
- Track completed commitments in a daily log and full archive

### A quiet journal

- Autosaved notes with a rich-text editor supporting headings, lists, bold, italic, underline, and strikethrough
- Mobile-friendly list and detail views for browsing and editing entries
- Fullscreen and pop-out note windows for distraction-free writing
- Adjustable editor height with persisted preferences

### Focus that breathes

- Built-in Pomodoro timer with a draggable, persistent floating timer
- Timer position is saved across sessions
- Bible break feature with guided 4-4-4-4 box breathing
- Optional completion chime for finished tasks

### Scripture, daily

- Verse of the day displayed on the dashboard and sidebar
- One-click access to the Scripture tab from the verse card
- Bible break breathing exercise for moments of pause

### Reminders & PWA

- Local push notifications before and at commitment deadlines
- Installable Progressive Web App that works offline
- Light and dark themes with system-aware defaults
- Mobile-optimized layouts and gestures throughout

## Principles

- **Slow is honest.** StillPoynt asks for your intention and gives the rest back.
- **Three things.** You can do many things in a day, but you can do three well.
- **Rest is a verb.** Built-in pauses for breath, scripture, and silence are part of the rhythm, not a reward.

## Technical Stack

- React 18 with TypeScript for the frontend
- Vite for build tooling and development
- Tailwind CSS and shadcn/ui for styling and components
- Framer Motion for transitions and micro-interactions
- Tiptap for the rich-text editor
- Supabase via Lovable Cloud for auth, data storage, and real-time sync
- vite-plugin-pwa for offline support and installability
- Deployed on Lovable / Vercel
